One place for all your agent skills

Different AI editors and agents expect reusable skills to live in different directories. Agent Skills Manager keeps a single canonical collection in ~/.agents/skills/ and lets you safely symlink it to every editor your team uses. It’s a simple time saver for anyone juggling Cursor, Claude, Codex, OpenCode, and project-specific skills.

Open Dashboard

Central Skills Hub

Store every skill in ~/.agents/skills/ with metadata, tags, and descriptions.

Agent Target Symlinks

Preview, move, and symlink directories for Cursor, Claude, Codex, OpenCode, and custom agents.

Project Skill Reviewer

Scan any project for .agents/skills/, .cursor/skills/, .claude/skills/, and other local skill directories.

Safe Workflow

Preview existing skills before replacing a directory with a symlink, with conflict handling.

How it works

  1. Start the app. Run agent-skills-manager run and open the dashboard.
  2. Manage skills. Add, edit, and tag skills in the central hub.
  3. Link editors. For each editor, preview the existing skills directory and create a symlink.
  4. Review projects. Scan a project and import its local skills into the central hub.

Keep the app up to date

Choose the update method that matches how you installed Agent Skills Manager.

Installed from source

Pull the latest changes and refresh the editable installation.

git switch main
git pull
.venv/bin/pip install -e ".[dev]"
.venv/bin/agent-skills-manager run

Installed from PyPI

Upgrade the package, then start the app again.

pip install --upgrade agent-skills-manager
agent-skills-manager run

Already running? Stop the server with Ctrl+C, restart it, then hard-refresh your browser with Cmd+Shift+R on macOS or Ctrl+Shift+R on Windows and Linux.

Keep this tool local. It manages files on your own machine and does not need network access.
